### 02:40-03:20 弹体扫气链路打通：case 模板 + 全参数化驱动 + 校验点出数
- 背景: 曼波问「现在我要干什么出数据集」。答复要点：**aero_table.csv 是 A/B 两路线共同前置，不必等冻结会**——冻结会只定表的边界（β/舵偏范围），CFD 算的是原始力/力矩，S_ref 与符号只是后处理换算系数，可后改。无悔路径 = 立刻建 case 跑校验点。
- 变更（`openfoam/airframe-sweep/`）:
  - `case_template/`: v12 全套（blockMeshDict 远场 15.6×9.6×9.6m / snappyHexMeshDict / 0/{U,p,k,omega,nut} / constant/{transportProperties,turbulenceProperties} / fvSchemes / fvSolution / decomposeParDict / controlDict 含 forces 采样 CofR=全系统质心）
  - `make_case.sh <V> <α> [β]`: 自动算来流矢量 −V(cosαcosβ, sinβ, sinαcosβ)、k/ω 入流、CofR，异常安全
  - `run_case.sh <case> [nproc]`: blockMesh→snappy→checkMesh→decomposePar(按 nproc 覆盖分区数)→foamRun 并行(reconstructPar)
  - `post_process.py <case>`: forces 时均 → 风轴 CL/CD/Cm/CY/Cl/Cn → 追加 aero_table.csv；**纯标准库**（WSL pip 装不动 numpy 被外部管理环境挡住）
  - `run_sweep.sh`: V×α×β 网格批量扫，断点可续（有 results.json 跳过）
- 实验: 校验点 V=25 m/s, α=4°, β=0, δ=0 → 800 步 / 324936 格 / 8 进程 / 约 7 分钟
  → **CL=+0.2773, CD=0.7851, Cm=−0.5789, CY=−0.0014, Cl=+0.0021, Cn=+0.0099**；末段力振荡 0.000；残差 t=800 时 Ux 1.4e-4 / p 3.9e-4
- 结论/发现（三个真坑）:
  1. **snappy 零相交静默失败**：基础网格 0.3m > 弹径 0.15m，表面整个落在格子内部、与网格边零相交 → "Number of intersected edges : 0"、格数 53248 不变、**但日志仍正常结束**。必须用 `refinementRegions` 的 searchableBox（level 4）先提近体区。这是本次最值钱的坑。
  2. v12 字典语法三处硬要求：geometry 里 triSurfaceMesh 要显式 `file`（不能只靠 dict 键名）；refinementRegions 要显式 `mode inside`；STL 必须放 `constant/triSurface/`（不是 case 根 triSurface/）。
  3. MPI：WSL 的 slot 数 < nproc，需 `--oversubscribe`；decomposeParDict 的 numberOfSubdomains 必须跟 `-np` 一致（已让 run_case.sh 自动 sed）。
  另: forces 在并行下写 **case 根目录** postProcessing/（不是各 processorN），4 组三元组（pressure+viscous），不是 6 组。
- 物理合理性: CL>0 (α>0)、CD 0.78（平头圆柱按迎面积量级正确）、Cm<0（静稳定，Cmα≈−8.3/rad）、对称分量≈0。**但这批数不进表** —— 舵面 level 5 (9.4mm) 远粗于 3mm 舵厚，升力/稳定性由舵面主导，定量不可信。
