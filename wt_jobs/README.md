# wt_jobs — 本机最小任务包 (随时开启 / 随时停止)

> 2026-10-29 | 曼波定: 桌面机只打杂 + 任务要"随时开关"。
> 每个任务 = 双击一个 bat, 跑完自动退出 (J2 是服务, 关窗口即停), **无常驻后台、无状态依赖、幂等**。

## 任务一览

| 入口 | 干什么 | 时长 | 停止方式 |
|---|---|---|---|
| `jobs\j1_sync_audit.bat` | 从 qianli 拉蓝表/T2 数据 → 跑六锚审计 (A1-A5 + A6 基准锚) → 生成仪表台数据 | 2-5 min | 自动退出 |
| `jobs\j2_dashboard.bat` | 起本机仪表台 **http://127.0.0.1:8123** (禁缓存, 自检面板) | 常驻 | 关窗口 / Ctrl+C |
| `jobs\j3_t2_report.bat` | 拉 R8b LBM 力数据 + 折叠位对照, 出 fy 对称性报告 | ~1 min | 自动退出 |

**推荐流程**: 双击 J1 → 双击 J2 → 浏览器开 `http://127.0.0.1:8123`。数据旧了就再跑一次 J1 (J2 不用重启, 页面刷新即取新)。

## 目录

```
wt_jobs/
  jobs/    双击入口 (bat)
  lib/     实现 (纯标准库 python, 唯一依赖 = 本机 WSL ssh 通 qianli)
  www/     仪表台 (dashboard.html + 数据 JSON + three.js + 3D 网格) ← J1/J2 的交接面
  state/   拉回的原始表 (gitignore)
  out/     人读报告 (审计 / T2)
```

## 仪表台 v2 亮点 (先渲染稳, 再专业度)

- **自检面板** (右下角常驻): 数据 / three.js / WebGL 三个状态灯——再也不会"空白却不知道为什么"
- **禁缓存服务**: 修掉 v1 "内嵌正常、曼波浏览器空白" 的缓存嫌疑
- **2D 降级**: three.js 加载失败自动切 2D 俯视示意, 页面永远有东西看
- **覆盖热力图**: V×13α×7β 完成态, 当前工况闪烁
- **系数曲线**: CL/CD/Cm-α 多 V 叠加 + 红基准(折叠)对照 + CL_α 线性拟合标注
- **极曲线**: CL-CD 气动效率
- **3D 姿态**: 平行基准镖体, δ1..δ4 滑块绕真实铰链轴转舵, α/β 滑块摆来流箭头
