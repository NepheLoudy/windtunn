## 二、🔴 重大 bug：组循环 stdin 吞行（已修复 `e565624`）

**现象**: P02-P07 全部只跑第 1 组（11 例）就 partial 退出，每包少算 44 例。

**根因**: `while read < <(python3 ...)` 的循环体（run_sweep_v2 子进程）继承并消费了循环 stdin——python 组列表的后续行被吃掉。**历次修复链**：
```
原版管道 (子shell 丢 PACK_FAIL) → 修成 process substitution → 引入 stdin 吞行
→ 修成 mktemp 落盘 + done < file + run_sweep </dev/null 双保险 ✅
```

**影响面**: T0.5 各包少算 44 例/包。**判重防线使全部损失可回收**——修复版重跑同包自动跳过已完成组，只补缺失组。已四机同步并重启队列。
