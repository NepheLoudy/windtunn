## ver1.0 — 面向实物生产的大功率风洞设计

**目标**: 观测和实验飞镖镖体流线型。为满足目标风速 (试验段 25 m/s) 与绕流影响,
通过有限元分析手段设计仿真项目, 推算需要 3D 打印的风机蜗壳、扇面结构、风机尺寸与模型数据。**负责人: 张郭浩**。

**仿真手段与关键实测** (GPU LBM 全域 + OpenFOAM 交叉验证双引擎):

| 项 | 实测结果 |
|---|---|
| 全域网格 | 4mm 49.6M 格 (8GB 卡可跑) / 3mm 117.8M 格 (FP16S 压缩后 7.5GB 可跑) |
| 泵送流量 | 960rpm frozen rotor: Q=1.32 → **试验段 22.0 m/s**; 1100rpm 仅 22.3 (4mm 分辨率下转速杠杆失效) |
| **交叉验证** | OpenFOAM 五段 blockMesh (57600 格) simpleFoam k-ω SST, 2000 步 226s → **22.00 m/s, 与 LBM 完全一致** — 22 m/s 是物理真实值 |
| 25 m/s 差距 | = 涵道沿程损失 (设计优化空间), 非仿真精度问题 |
| 转速稳定图 | 790✗ / 960✓ / 1080✗ / 1180✓ rpm — 稳定窗口非单调, 转速选型有禁区 |
| 旋转口径 | frozen rotor 定量口径 (WT_ROT/WT_RPM 开关); 旋转模式瞬态为独立专项 |
| 3mm 全域谜题 | 泵送锁死 −0.019 m³/s (反向渗流稳定吸引子), 4mm 数值黏性天然抑制 — 分辨率-稳定性耦合专项, 修复方向 = 域设计 (已归档待重启) |

**产出**: 风机蜗壳/扇面 3D 打印参数、转速-流量工作曲线、试验段风速标定 (22.0 m/s 实测)、
可视化链路 (切片窗/全涵道动画/轨道环绕)、八站位流道测量+中心线诊断。
**可视化资产**: `WindTunnel3D` 渲染层 (红=固体叶轮/蓝=流动结构/绿轴/蓝轴语义定稿)。

**与 ver1.1 的关系**: 1.0 回答「风洞造出来什么样」; 1.1 把镖体放进这套流场里, 回答「镖体在里面经受什么」。

## ver1.1 — 纳入镖体的风洞全链路 CFD 架构

**目标**: 建立从 CAD 到气动力系数表的**全自动、可审计、可重放**的 CFD 扫气架构, 纳入真实镖体几何与舵面自由度。

### 架构 (双引擎 + 全链路管线)

```
CAD (STEP 30 实体) ──解析──> 镖体装配 (B 系, 114.6×239.3mm, X 布局四板翼+四舵 δ1..δ4)
   │                              │
   ├─ deflect_stl.py (v4 真铰链轴) ──> 16 δ-位形几何 (独立 Rodrigues 自检 ±10.0000°)
   │
   ├─==> OpenFOAM v12 (CPU 14 核)  — snappyHexMesh L5/L7→L6/L8, simpleFoam k-ω SST
   │       make_case → clone_case(网格复用) → run_solve(14 核并行) → post_process(风轴系数) → aero_table
   └─==> FluidX3D (GPU 5070)       — LBM 瞬态/分支/舵效快扫 (300k 步 ~4min/例)
           逐零件体素化+TYPE_X 补标 / read_stl_assembly 装配变换 (v4asm)
```

### 关键实测与事故沉淀 (全部有仓库事件流留痕)

| 类别 | 事件与结论 |
|---|---|
| 几何链 | STEP 解析 (30 实体/体积 155.62cm³)、铰链轴四代纠错终局 (v4 真轴=双耳孔心连线, 四轴汇交 hub)、镖头凹陷保留 (气动效应是构型一部分) |
| 基准事故 | v0.9 表 δ=0 实为"顺翼面折叠 ±45°"位形——全表归档重跑; **δ=0 = 舵面平行弹轴** 基准切换 |
| GPU 管线缺陷 | read_stl_raw 每件 STL 强制居中+缩放 → 30 件穿插成团 (T2/F4 历史数据作废重定标); 修复=自读 STL+装配变换 (v4asm), gate fx −37.5→−63.1 换带实证; **差分实验 (d0 vs d1p) 是击穿手段** |
| 力矩 bug | object_torque 域中心化坐标减绝对 center → 全部力矩列 = T_true − center×F; 线性精确后处理恢复 (T_true=T_rep+center×F), 229 例零重跑 |
| 三防 | 断电零自启 → 桌面哨兵 30min 拉回 + recover_table 回填 + chain 补跑 (阈值已修 546); 批队列断点续跑+原子锁为标配 |
| 审计链 | A1-A6 逐行审计 (CY 偏置/β 镜像/CL_α 漂移三锚)、对拍锁死 (LBM↔FVM parity 89 点 2.8e-15)、事件流 66+ 条全程可回放 |

### 验证体系 (跨引擎互证)

- **FVM↔LBM 对拍**: CD −0.14% (六项全<2%); Nx² 晶格标度律 (p=−2.001, 归一化后四级 ±2~5%)
- **确定性**: 同输入重跑 bit-identical (rel_diff=0.0)
- **手性耦合**: fy 的 sign(α)·sign(β) 交互项 — 团块/真实弹体双几何复现 (p=4.7e-4)
- **定常吸引子**: α=12.5°/15° 长时序 1.2M 步, 末段极差 0.12~0.19% (判据 2%)

**与 ver1.2 的关系**: 1.1 是产线; 1.2 是产线的交付物——把架构的产出收敛成「RL 直接可查的数据集」。

## ver1.2 — 面向强化学习飞镖控制的纯粹仿真气动数据集

**目标**: 剥离风洞硬件与架构细节, 交付**RL 直接可查**的定常气动数据集——状态 (V,α,β,δ) → 力/力矩, 运动积分归 MuJoCo (解耦边界: 表只管"状态→力")。

### 交付物 (v0.97-handoff, 2026-11-15)

| 件 | 内容 | 状态 |
|---|---|---|
| **气动主表** | 546 工况 (V{20~25}×α{−15~15,13 档}×β{−15~15,7 档}, δ=0), 546/546 全表达成 (2026-11-15, a0_b0 家族松弛 0.5 治愈) | ✅ |
| **查表实现** | `lookup_aero.py` — 6 维三线性插值, 出域钳位+警告, damp 动导数默认启用, 热加载 | ✅ 自测 7 项+parity 2.8e-15 |
| **动导数** | Cmq=−0.2583 / Cnr=−0.2677 (tfixed + 11-16 归一口径修正, `extract_damp.py` 守门 ×2.9372) / Clp=null (低于噪声底诚实声明) | ✅ 实装 |
| **舵效表** | 10 位形 (8 单舵 ±10°+2 合成) × (V20,α0,β0) @L6/L8 — `guidance_sim/aero/delta_table_t1q.csv` | ✅ 已入库 |
| **交接文档** | `dataset_delivery.md` v0.97-handoff §0 交接指南 (清单/Quickstart/限制七条/责任分工) | ✅ |

### 核心气动结论 (RL 增稳设计的定量输入)

| 结论 | 数值 | 对 RL 的含义 |
|---|---|---|
| **双轴强静不稳定** | Cm_α 分段 +0.59 (线性区)/+0.21 (5~10°); Cn_β=−0.434/rad | 弹体天然发散, **增稳是硬责任, 纯 PN 外环必发散** |
| 升力线性 | CL_α=+2.40/rad (R²=1.000), ±10° 线性+±15 弯曲 | 可信域 α/β∈[−15,15] 内插值安全 |
| 特征验收 | 8/8 规划特征兑现 (镜像 2.8%/跨 V 0.4%/压心自洽) | 数据集与规划文档零偏差 |
| damp 补偿 | Cmq/Cnr 同频等效阻尼 (k≈8.7 超准定常域, 保守偏小) | 防 RL 高频抖舵; Clp 滚转无补偿如实声明 |
| 可信域 | α/β∈[−15,15°] (15°=奖励终止阈值), V∈[20,25] | 出域=未标定, 补点走 append-only 按需服务 |

### 已知边界 (诚实清单, 详见 dataset_delivery §0.4)

GPU 线 Re 限界 (Re≈1100 vs FVM 1.5×10⁵ — 升力类量不跨 Re 存活) / LBM 域壁干扰 (阻塞比 61%,
定性结论可用量级需校验) / com/惯量 PLACEHOLDER (实机称重前力矩绝对精度上限) / X 布局四舵独立角
与 spec + 布局混控约定的映射差异 (delta-mode 设计冻结项)。
