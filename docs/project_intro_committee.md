# 飞镖气动仿真项目介绍（组委会版）

> 本文档为面向组委会的项目与意图介绍，按技术报告体例撰写。
> 完整技术细节与数据出处见 `docs/aeroacoustic_project_versions.md`；全部数字可在仓库 devlog 与事件流中逐条回放。

## 一、项目定位与研究目标

本项目构建一套覆盖 **风洞设计验证 → 镖体气动建模 → 气动力数据集交付** 全链路的 CFD 仿真体系。研究对象为一型飞镖镖体（全长 239.3 mm，展向尺寸 114.6 mm，X 形布局四板翼，四舵面独立偏转 δ1–δ4）。

项目意图：

1. **为实物风洞建造提供设计依据。** 实物风洞（试验段设计目标 25 m/s）由张郭浩负责建造；仿真侧先行完成风机蜗壳、扇面等关键部件的选型验证，并输出 3D 打印制造参数。
2. **为制导控制算法提供气动力数据基础。** 该镖体属静不稳定构型，稳定飞行依赖机载实时控制；控制算法（经典比例导引基线与强化学习增稳）在训练与验证阶段所需的气动力/力矩数据，由本项目数据集统一供给。
3. **以系统化仿真替代大规模实物试验。** 实物试验单次仅覆盖单一状态，且无法观测内部流场结构；数值仿真可系统性覆盖数百个状态组合，全部结果可复核、可回放。

项目按三个版本演进，同一镖体几何模型（CAD STEP 装配，30 实体）贯穿全程。

## 二、ver1.0 —— 大功率风洞设计仿真验证

**阶段目标**：在实物制造开工前完成风洞整机气动设计的仿真验证，输出试验段风速标定、风机转速工作区间与关键部件制造参数。

**技术途径**：风洞全链路（风机—蜗壳—整流段—收缩段—试验段）全域建模；采用格子玻尔兹曼方法（LBM，FluidX3D，GPU）求解风机驱动下的整场流动，并以 OpenFOAM（RANS，simpleFoam，k-ω SST，五段结构化网格 57,600 格）独立复算，构成双方法交叉验证。

**主要结果**：

| 项目 | 结果 |
|---|---|
| 试验段风速 | 960 rpm 定常口径，泵送流量 Q=1.32 m³/s，试验段 22.0 m/s（LBM 4mm 全域 49.6M 格） |
| 交叉验证 | OpenFOAM 独立复算得 22.00 m/s，与 LBM 结果一致，确认该值为物理真实解 |
| 25 m/s 差距归因 | 涵道沿程损失，属设计优化空间，非仿真误差 |
| 转速稳定窗口 | 790/960/1080/1180 rpm 稳定性呈非单调分布，为实物转速选型划定禁区 |
| 制造输出 | 风机蜗壳/扇面 3D 打印参数、转速—流量工作曲线、试验段风速标定 |

同期建立风洞内部流场可视化体系（切片动画、整机环绕渲染、八站位流道测量与中心线诊断），用于设计评审与成果展示。

## 三、ver1.1 —— 全链路 CFD 气动数据生产架构

**阶段目标**：将「CAD 模型 → 气动力系数表」的转换过程建成全自动、可审计、可重放的生产线，纳入真实镖体几何与舵面全部自由度。

**架构**：

- **几何链**：STEP 装配（30 实体）解析 → 舵面偏转几何自动生成。铰链轴经四代迭代定案于双耳孔心连线（四轴汇交），装配自检精度 ±10.0000°。
- **双引擎分工**：OpenFOAM v12（CPU 14 核，snappyHexMesh L6/L8，simpleFoam）承担定量档；FluidX3D LBM（GPU，约 4 min/例/30 万时间步）承担瞬态、分支特性与舵效快扫档。
- **自动化链路**：建 case → 网格复用 → 并行求解 → 风轴系数后处理 → 自动入库；批队列断点续跑与原子锁为标配，异常自动恢复。

**质量体系**：

- 双引擎对拍：六项关键量偏差全部 < 2%，阻力系数偏差 −0.14%；
- 网格收敛性：晶格面积标度律指数实测 −2.001（理论值 −2），四级分辨率归一化后力系数 ±2–5% 一致；
- 确定性：同输入重跑结果逐位一致（rel_diff = 0）；
- 过程留痕：逐日开发日志与 66+ 条领域事件流，任一数字可回放至原始日志与脚本。

## 四、ver1.2 —— 定常气动数据集交付

**阶段目标**：面向强化学习控制训练，交付状态 (V, α, β, δ) → 力/力矩 的即查即用数据集；运动积分由控制侧仿真环境（MuJoCo）承担，两侧职责边界明确解耦。

**交付物**：

| 交付件 | 规格 |
|---|---|
| 气动主表 | 546 工况（V 20–25 m/s 六档 × α −15°–15° 十三档 × β −15°–15° 七档，δ=0），全量收敛 |
| 查表程序 | `lookup_aero.py`：六维三线性插值，出域钳位与警告，动导数补偿可启用，支持热加载 |
| 动导数 | Cmq = −0.2583、Cnr = −0.2677；Clp 低于噪声底，如实声明不予给出 |
| 舵效表 | 10 位形（四舵独立 ±10° 及合成）×（V20, α=0, β=0），L6/L8 精度档 |
| 交接文档 | 使用指南、可信域声明、已知边界清单、责任分工 |
| 网页三维观察台 | 浏览器端任意姿态流线可视化，与主表数据同源 |

**核心气动结论（控制设计输入）**：

1. **双轴静不稳定**：俯仰 Cm_α = +0.59/rad（线性区，|α|≤5°）、航向 Cn_β = −0.434/rad，斜率方向均为失稳方向——纯比例导引外环必然发散，增稳为控制算法的必要功能；
2. **升力线性度**：CL_α = +2.40/rad，±10° 内保持线性、±15° 出现弯曲，可信域内插值安全；
3. **可信域**：α/β ∈ [−15°, 15°]，V ∈ [20, 25] m/s（扩容完成后为 10–25 m/s）；出域查询被拒绝并提示补算，不提供未标定数据；
4. **数据边界声明**：GPU 线雷诺数限界（Re≈1100，升力类量不跨 Re 外推）、LBM 计算域阻塞比 61%（定性结论可用，定量需校验）、重心/惯量为占位值（待实机称重后经 recompute_cm 零重跑刷新全表力矩）。

## 五、当前进展与后续计划

- **数据集扩容（P01）**：低速段 V10–20 m/s 新增 935 工况，四机算力网络（主力服务器 + 两台迷你主机 + 台式机 GPU 节点）分片并行生产中；完成后主表覆盖 V10–25 m/s 全速段。
- **运维体系**：FleetMonitor 定时巡检四机状态、自动生成算力晨报、值班巡检；异常自动告警。
- **开源**：代码、文档与全部过程记录托管于 GitHub（github.com/NepheLoudy/windtunnel）。
- **后续路径**：实机称重数据回填（力矩全表分钟级刷新）；舵效层 2/3 扩展（±20°、耦合位形）；T1 力矩可信档全量扫描排期；LBM 计算域重设计。
