→ 重挂 T1 收割机（PID 6405）。仓库正本 chain_t1_v3.sh 已补前置条件警示注释；
**运行中的 chain 刻意未动**（bash 对运行中脚本增量读取，原地改会炸执行）。

### 🔴 雷2：guard 首跑咬出的 pkill 自杀新变体

老教训是"字符类断自匹配"（`pkill -f case_reape[r].sh`），本轮升级：**同一条命令里如果
还有含明文目标串的重启文本（`bash ~/case_reaper.sh ~/sweep_t1 600`），pkill 照样自杀**——
正则匹配的是整条远程 shell 命令行。教训入库：**pkill 与"含明文目标串的命令"绝不同屏**，
拆成独立 ssh 调用。
