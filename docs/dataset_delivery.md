## 0. ⚠ v0.9 → v0.96 基准与几何变更 (必读)

**① δ=0 的定义变了**: v0.9 表的 δ=0 实际是"四舵顺翼面折叠 ±45°"位形 (STEP 装配态,
非工作零位); v0.96 起按曼波裁定 **δ=0 = 舵面平行弹轴 (顺流位)**。
两个基准之间不可混用 (舵面差整整 45° 满偏)。v0.9 红表归档不删, 以后当
"全舵满偏 45°"极端标定点用。

**② 几何两处修正 (2026-10-30, 曼波指正)**:
- **铰链轴心精拟合**: 旧轴位置偏 2.000mm (方向零偏), 已按舵根空心圆柱孔心修正
  (逐切片圆拟合, 圆心 RMS 0.000mm, 孔径带均值 r=1.690mm)。δ 旋转语义 = 绕孔心轴右手正转。
- **镖头圆柱深孔填实**: 只封 ⌀16.6×8.7mm 深孔段 (+2.51cm³), **鼻端台形凹陷完整保留**
  (凹陷气动效应是构型的一部分)。弹体体积 155.62 cm³ (原 153.3)。

v0.9 声明中的 "CY(β=0)=−0.135 恒定偏置" 已随基准切换**溯源关闭**: 来源 = 折叠舵组
手性净侧力, 蓝基准 (平行位) 下 CY 应 ≈0 — 这是 v0.96 表的第一道验收锚 (audit A6)。

## 1. 这是什么

镖体 (南航镖复刻构型, X 布局四板翼 + 四片尾缘舵) 的**定常气动数据库**:
给定飞行状态 → 查表输出六分量气动力系数, 供 MuJoCo 闭环 (识别→制导→舵机→六自由度) 使用。

**查表签名** (7 维输入 → 6 系数, 引擎无关):

```
lookup_aero(V, α, β, δ1, δ2, δ3, δ4) → (CL, CD, Cm, CY, Cl, Cn)
输入:  V [m/s]; α/β [deg]; 四片舵独立角 [deg] (绕各自铰链轴右手正转)
输出:  稳定轴系数 — CD 沿来流, CL ⊥来流(向上+), Cm 绕体轴 y (+抬头)
参考:  S_ref, L_ref 见表头; 力矩参考点 = 质心 (mass_properties.json)
```

**位姿说明** (为什么不是全位姿): 定常气动只依赖 (V, α, β, δ) — 姿态 3DOF 中相对
重力系的方位不进入气动 (空气不知道重力朝哪), 绕速度轴自转是气动无关自由度。
全位姿由 MuJoCo 积分; 本表只负责"状态 → 力"这一段。

- 出域行为: clamp 到表边界 + RuntimeWarning — **warning 即补点信号**

## 5. 对 RL/DAns 路线的三条使用建议

1. **侧向分量 (CY/Cl/Cn) 初期降权或加噪声**: 大攻角区分支不确定性 ±0.03 — 闭环舵修能兜住, 但开环使用请谨慎;
2. **出域即补点**: 策略探索到表外状态时把工况发给 CFD 侧 (格式 = 表行), 扫完热加载;
3. **Cmα>0**: 专家 PN+PID 的内环必须带姿态稳定项 (spec §4.5.2 双环结构已含), 纯 PN 外环直接飞会飘。
