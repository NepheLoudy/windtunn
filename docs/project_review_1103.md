## 三、T2 GPU 线数据质量审查（本轮重点，三发现）

**进度**：179 例完成（gate 1 + 粗格分支 66 + 粗格种子 32 + Re 阶梯 4 + 330/440 收敛验证 6 + 细格分支 54 + 细格种子 16），正跑 fs_a15（~17min/例@440），剩细格种子 16 + 角点 + 660 锚点 ≈ **今晨~上午收尾**。

### 3.1 🔴→🟢 粗细格 fx 差 4 倍 —— 11-03 下午翻案：是晶格单位标度，不是不收敛

**同日 17:56 复审（收敛阶梯补齐后）推翻上述"不收敛"初判**。四级网格链（α=12.5, β=0, Nu×Nx 恒定 Re=lattice 1100）：

| nx | fx (lu) | fx/Nx² | 与 660 偏差 |
|---|---|---|---|
| 220 | −37.53 | −7.754e-04 | −0.6% |
| 330 | −83.06 | −7.627e-04 | −2.2% |
| 440 | −145.23 | −7.502e-04 | −3.8% |
| 660 | −339.80 | −7.801e-04 | 0 |

- **Richardson 斜率 p = −2.001**：fx 严格按 Nx² 标度——这正是 LBM 晶格单位的**面积标度律**（F_lu ∝ ρ·U²·A_lu，A_lu∝Nx²），不是发散。**Nx² 归一化后四级散布 ±2%（220 vs 660 只差 0.6%）**。
- 我早上把"fx 差 4 倍"判成不收敛，漏了把晶格单位换算掉——**跨分辨率比较 LBM 力必须先做物理单位换算或 Nx² 归一化**，原始 lu 值跨 nx 直接比是量纲错误（同族教训：跨单位比较前先问"这个数的单位随什么变"）。
- **判读二才是对的且更正**：±2% 的残余散布（330/440 轻微下凹）才是真实的网格收敛残差——T2 主产出（nx440 批次）的量级标尺**成立**，比 FVM 网格敏感性（力 4%/力矩 10-17%）还紧。
- 交叉验证 |fy/fx|(660)=0.048 落在 FVM 同工况比预估 0.04-0.1 带内——两代码物理形态一致。
- ⚠ 保留项：绝对物理量级（牛顿）换算依赖 cpm=Nx/0.2386 与参考面积换算，做 dataset_delivery 汇总时用 FVM 为准的既定口径不变。

### 3.2 🟠 大攻角 fy 镜像不对称：手性耦合 vs 分支随机

细格分支矩阵 β=±b 的 |fy| 镜像比 0.03~13.4（全线 ASYM），但**模式高度规律：α>0 时 fy(β+)>fy(β−)，α<0 反号**——sign(α)·sign(β) 的交叉耦合，与 CPU 侧 A2 手性指纹（dCY 15-23%）同向同源。α 反对称（β=0）方向检查 OK（fy(+a)≈−fy(−a)，残差 ~10-20%）。

- 判读：大概率是**手性几何（X 布局旋转对称非镜像对称）× 大攻角非对称涡**的物理效应，不是 bug；但需要 β 细扫描（±2.5° 步进）区分"光滑交叉项"与"分支跳变"。
- 附带发现：fy(β) 单调性只在 β>0 侧成立，β<0 侧非单调——分支结构特征，正是 T2 的科学目标区。

### 3.3 🟠 种子零散布：确定性锁定，"瞬态统计"目标未达成

8 seeds 的 fy 全组差 <0.07%（fs_a±12.5 / s_a±12.5 / s_a±15 五组全如此）。SEED 注入已验证**真实存在**（setup.cpp L32-33 读 env → L66-70 hash 扰动场），所以这不是白跑，而是一个真实结论：

> ±3% 量级初始扰动在 300k 步内被数值耗散完全吃掉——该流动在此时窗内**无初始条件敏感性**，每个工况锁死单一分支。"种子统计"实际测到的是求解器确定性，不是流分支统计。

- **行动**：分支统计要成立，需要①长时序（1 例 600k-1M 步看 fy(t) 是否自发切换分支）或②更强/更靠近分离区的扰动（涡量场扰动 vs 速度场扰动）。先做①，成本 1 例 ~35min（440）/ ~2h（660 级）。

**长时序实验结果（11-03 晚补记，T3 复工后首批产出）**：lt_a12.5_b0 已跑完 1.2M 步（2401 点，~70min 实测）。fy 分段均值六窗全程 **−7.157 → −7.168**，除起始 200k 步瞬态建立段（sd 0.238）外，五个窗 sd≈0.0014、**全程极差 0.13% of mean**——**4 倍时窗内 fy(t) 无任何分支切换迹象，锁死在单一吸引子**。结论升级：大攻角 LBM 解在该参数下是**确定性定常吸引子**（300k 步的"稳态"不是没收敛，是真稳态），"分支不确定 ±0.03"问题在该流动区**不存在**——RL 大攻角侧向分量可以放心用单值（T2/T3 结论直接改写）；唯一保留：α=15° 更高攻角区未验证（等 T3 队列）。
