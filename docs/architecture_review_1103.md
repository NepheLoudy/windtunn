## 三、专项：观察台动态立体受风工况渲染（曼波本轮需求）

### 3.0 对标"成熟风力项目"是什么样
风电 SCADA 3D 视图的标配：**风场来流可视化（粒子/流线）+ 叶轮动态旋转 + 表面压力/载荷着色 + 功率/风速仪表联动 + 时间轴回放**。映射到我们：涵道风洞 = "风"从收缩段进来→稳定网→试验段→扩散段；镖体扫气线 = 来流绕镖体+舵面偏转。曼波要的"像成熟风力项目一样"，本质上就是把这些从 MATLAB 离线 mp4 搬到浏览器里**交互+实时**。

### 3.1 现状盘点（侦察兵证据，全部带行号）
- dashboard.html 546 行 Three.js：镖体网格渲染/舵偏滑块/PCA 中轴/重心球/来流箭头/相机自转全有——**骨架好于预期**；
- 但：无流场/切面/等值面/粒子；动画循环只自转（`dashboard.html:465-468`）；httpd 只有静态+mass_props（`httpd.py:60-107`）；风洞本体几何（tunnel_body.stl）只在 MATLAB 端；流场数据（vtk/raw）从不出 MATLAB/solver 主机；
- MATLAB 端渲染语义已定稿（红固体/蓝流动/三层等值面/动态叶轮）——**语义层可以直接照搬 web**，等于翻译而非重新设计。

### 3.2 方案设计（三阶段，每阶段独立可用）

**Stage 1 — 风洞几何+受风工况静态立体化（~1 天，立即可做）**
1. `tunnel_body.stl` + 蜗壳螺旋/整流网标记 → 走 make_mesh_json 同款管线量化成 `tunnel_mesh.json`（web 端半透明壳，照搬 orbit_mov 的灰壳语义）；
2. 镖体/风机叶轮放进涵道正确位形（坐标变换一次标定）；
3. 来流粒子流线：Three.js `BufferGeometry` + 粒子系统，风速/α/β 滑块联动（现有 `setFlow` 扩展成粒子场），试验段截面显示实时 Q/风速数字（数据从 dashboard_data.json 拿，已有链路）；
4. 叶轮旋转动画（ω 可调，演示档 360rpm 语义）。
   → 交付：观察台新增「风洞视图」标签页，看涵道里的受风状态，所有数据走已有 2min 同步链。

**Stage 2 — 真流场切片/等值面上 web（~2-3 天，核心拟真）**
1. **场数据转换器**（桌面侧新工位）：FluidX3D `u_*.vtk` 结构化网格 → 降采样 → 量化 → 二进制分块（.bin + manifest.json，参考 make_mesh_json 量化经验）；
2. Three.js 三向切片面（texture2D 色图，turbo LUT 照搬 MATLAB 语义：蓝流动/红固体撞色铁律继续守）+ marching cubes 等值面（|U| 三层阈值 0.90/0.55/0.30×Veff 语义照搬）；
3. 时间轴：快照序列播放/暂停/拖拽（MATLAB explore_gpu 的滑块交互照搬）；
4. 数据量策略：4mm 域 49.6M 格全量上 web 不可能——**切片面只传切片数据（每张 ~80k 格量化后 <1MB）+ 等值面用预烘焙 marchinge cubes 顶点（每帧 2-5MB，隔帧抽稀）**；快照 28 帧的现有 R1 数据即可喂第一版。
   → 交付：浏览器里拖时间轴看涵道内流速场演化——这就是"动态渲染立体受风工况"的本体。

**Stage 3 — 求解运行实时联动（~1 天，SCADA 化收尾）**
1. WT_sync（2min）已拉 forces.csv/状态 → 增加"当前快照"拉取（vtk 最新帧→转换器→www/）；
2. 观察台风洞视图加"实时"模式：数据年龄徽章已有机制照搬（30h 不可见教训：无数据=显式红灯，不装死）；
3. 求解端 (qianli/台式机) 只需定期吐 vtk 快照——FluidX3D 已有 WT_VTK 输出机制，零改动。
   → 边界诚实：LBM 运行中实时切片 = 快照节拍级别（分钟级），不是真流式；这个预期先对齐。

### 3.3 与既有资产的关系（不造轮子清单）
- 渲染语义/色图/等值面阈值/动态叶轮：照搬 explore_gpu.m 定稿语义（10-02 定的，别重新发明）；
- 量化/版本戳/禁缓存/年龄徽章：照搬 make_mesh_json + dashboard 既有机制；
- 撞色铁律：固体红系/流动蓝系——曼波三次误报教训，web 端 shader 直接继承；
- Stage 2 的 vtk 转换器与 MATLAB read_fluidx3d_vtk.m 读同一份数据格式，解析逻辑可互相对拍。

### 3.4 制导线（镖体）要不要同款？
镖体扫气线的流场渲染目前为零（侦察兵确认）——但它的消费端是 MuJoCo RL（要看的是系数表不是流场），**建议不做**，Stage 1-2 只做涵道风洞线。若曼波想看镖体绕流，T3-P1 的 LBM 对拍快照顺带就能出（同一套 Stage 2 管线喂镖体几何即可，边际成本 ~0）。
