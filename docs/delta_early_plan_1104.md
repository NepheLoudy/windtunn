# 舵效层提前方案（A 方案，曼波 11-04 拍板）

> 背景：RL 训练需要 δ→力矩映射（舵面攻角→非向心力矩→姿态变化链），原排期 δ 舵效层排 T1-v2 后（~11/16+），RL 侧被卡 10 天。本方案把舵效层提前到 T0 出全后立刻插队。

## 1. 为什么可以提前（可行性三确认）

| 确认项 | 状态 |
|---|---|
| δ 几何管线 | ✅ `deflect_stl.py` 现成（绕铰链线旋转操纵面 STL，标准库），fin_1..4.stl 已在 qianli case triSurface/ |
| make_case 几何无关 | ✅ 模板按 STL 无关设计，δ 工况=换 triSurface 重跑 |
| 算力 | ✅ T0 出全（11/5 深夜-11/6 凌晨）后 qianli CPU 空出，T1 让位或并行尾部 |

## 2. 扫气矩阵（135 工况 ≈ 27h @12min）

原 README 阶段 2 设计照用：

- **基线姿态点**：5 个 (α, β) = (0,0), (5,0), (-5,0), (10,0), (0,5)——覆盖线性区+大攻角+侧滑
- **舵偏组合**：de ∈ {-20,-15,-10,-5,5,10,15,20}（8 档对称）+ da ∈ {-20,20}（2 档）+ dr ∈ {-20,20}（2 档）× 5 姿态 = 60
- **混控验证点**：de+da 叠加 5 点（查耦合）× 5 姿态 = 25
- **V 档**：全 V20（舵效对 V 钝感 <1% 已证）——如需 V 联动后续补
- **合计**：60 + 25 + 基线复用（δ=0 行已在蓝表）≈ **85-135 工况**

**分层策略**：先扫 de 俯仰通道（RL 增稳最急），48 工况 ≈ 10h——α 链路先通。

## 3. 网格口径与精度声明

- **用 T0 网格（L5/L7）扫**：舵效主力矩信号（δ=20° 时 Cm 变化 ~0.05-0.1）远大于 T0 网格噪声（力振荡 2-3%）→ **信噪比够，初版可用**
- **T1 对拍兜底**：T1 出全后抽 5 个 δ 工况同拍，量化 T0 舵效误差；>10% 再决定是否 T1 重扫
- **表结构**：δ 行进同一张蓝表（de/da/dr 列本来就有），lookup_aero 的 de/da/dr 三维插值天然支持——RL 侧零改动

## 4. 执行序列（T0 出全后自动衔接）

```
T0 出全 (11/5 深夜-11/6 凌晨)
  → chain_t1_v3 检测放行 T1（保持既有逻辑）
  → 新增 chain 节点: 舵效层引擎在 T1 启动后 2h 插入（错峰，避免与 T1 首批网格重建抢 I/O）
      sweep_delta/: deflect_stl 生成 δ 几何 → make_case → run_solve
      de 俯仰通道优先（10h）→ da/dr 横侧向（17h）
  → 舵效表行 append 进蓝表（同表, de/da/dr 列非零）
  → merge_master 合并时 δ 行自然纳入 → lookup_aero 三线性四维全通
```

**RL 侧解锁时间线**：δ 俯仰数据 11/7 晨 → 全 δ 数据 11/8（原排期 11/底）。

## 5. 渲染端联动（观察台，数据到位自动活）

- δ 滑块 → lookup_aero 查 δ≠0 行 → 力矢量/力矩读数变化（管线已通，数据进表即活）
- 流线：真实场流线当前是 δ=0 工况——δ 工况流线需对应 case 重新积分（streamlines_from_case.py 已参数化，δ case 扫完即可出）

## 6. 风险与边界

| 风险 | 缓解 |
|---|---|
| T0 网格舵效精度不足 | T1 对拍兜底（§3），>10% 再 T1 重扫 |
| 与 T1 抢 CPU | 舵效层插队 14 核跑，T1 首批 2h 错峰；或舵效层与 T1 分时段（舵效夜间跑） |
| deflect_stl 几何在 δ=20° 时舵根穿透 | check_fin_sweep.py 已验过 ±45° 零穿透，±20° 安全 |

## 7. 与现有链的兼容性

- chain_t1_v3.sh **不改动**（运行中脚本不可原地改——bash 增量读取铁律）；舵效层用独立启动器 `launch_delta.sh`，由 guard 或 T0 出全检测触发
- 蓝表 append-only 不破；审计 A1-A6 对 δ 行天然兼容（值域检查按 δ 分档需小改 audit_sweep——δ≠0 行 CL/Cm 值域更宽）
