## 2. T2 排查战果 (本轮核心工作)

**8 轮编译排障 + 球标定实验 + 3 组对照跑** (R3/R5/R6/R7), 全记录 devlog。最终图景:

| 实验 | 结果 | 结论 |
|---|---|---|
| 球标定 (Re=1000, 理论 Cd 0.47) | **Cd=0.812, bias 1.73x** | 体素阶梯 1.1x + 阻塞比 1.1x + 低分辨率 BL 1.15x + 力核语义残余 |
| R3 (带舵, 六面 TYPE_E) | Fy≈244 lu 非零 | 全部来自舵面 (3 格厚锯齿) |
| R5 (仅上游 TYPE_E) | Fy/Fz→0 | **错误方向**: y/z periodic 抽走法向力; 六面 TYPE_E 才是官方 CRM 配置 |
| **R7 (body-only + TYPE_X)** | **Fy 精确=0** | LBM 对称性完美; **舵面贡献 77% 阻力 (3mm 舵在 1.08mm 格的锯齿群)** |
| SUBGRID 有无对照 | 力几乎不变 | Re 失配假设排除 |

**T2 定位决策**: LBM 绝对量级在粗网格+薄舵下不可信 (bias 1.73x + 舵锯齿), 但
**趋势/相对比较/瞬态统计完全可用**。与 FVM 的关系是**互补而非替代**:
- 绝对量级 → 以 T0/T1 (FVM) 为准
- 大攻角瞬态统计、涡脱落频率、分岔区时均 → LBM 独占优势 (快 2 个数量级)
- 跨代码对拍 (趋势层) → 拟真度背书
