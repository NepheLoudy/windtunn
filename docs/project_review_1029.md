## 1. 复盘: 舵偏基准事故 (本轮最大问题)

### 1.1 事故链 (时间顺序)

| 环节 | 事件 | 根因 |
|---|---|---|
| 10-23 | STEP 解析, 舵 STL 从装配态直接提取 | **装配态 ≠ 工作零位**——STEP 里舵是"顺 X 翼折叠"存放的 |
| 10-23 | 铰链轴定稿 (曼波指认方式), deflect_stl 机制建成 | 工具对了, 但 δ=0 的定义没被显式钉死 |
| 10-24~28 | T0 扫气 364 工况 / T1 扫 36 工况 | 全跑在折叠位形上; CY≈−0.13 恒定偏置被"手性几何"解释**部分正确但掩盖了主因** |

### 1.2 根因分析 (为什么 99.5 小时白烧)

1. **直接原因**: 10-28 基准决策落地时只生成了几何 + 改了 T1 启动器, **T0 正在跑的引擎没人回头核对 GEOM_DIR**。当时注意力在"仪表台不可见 + T2 排障"两条线上。
2. **流程缺口**: 基准切换这种**全局性决策没有检查清单**。"哪个机器、哪条管线、哪个启动脚本引用了旧几何"没有逐一排查——T1 改了、T0 漏了。
3. **认知盲区**: "手性解释 CY 偏置"（10-27 定性）在几何层是对的, 但**阻止了进一步的追问**: 折叠 ±45° 混号才是偏置的完整来源。手性是"为什么不是镜像", 折叠是"为什么有净侧力"——两层结论叠加后我停在了第一层。
4. **审计工具的盲区**: audit_sweep 五检 (跨V/镜像/偏置/值域/重复) 全绿**不是因为数据对, 而是因为五检查的全是"表内部自洽"**, 没有一项对照"几何基准的外部真值"。基准错误在表内部是无迹可寻的。

### 1.3 损失盘点与止损

- **损失**: T0 99.5h + T1 ~23h (36 工况) = 约 5 机日。
- **止损 (红数据不删的理由)**: 折叠位 = 四舵同时偏 ±45° 的**真实物理位形**。舵效层扫完后, 它恰好是"全舵满偏"标定点, 可验证舵效叠加假设的极限误差。`aero_table_foldedfin_T0.csv` 已入库归档。
- **救回**: V20_a0_b0 发散问题定位+修复 (松弛 0.9→0.5), 这个知识在新基准重跑中依然生效。

### 1.4 流程修正 (立即生效)

1. **全局基准/参数变更 checklist**: 任何跨工况的决策 (几何基准/参考面积/坐标系/单位), 落地时必须枚举"哪些引擎/脚本/文档引用了旧值"并逐一核对——**改一处不等于改了全局**。
2. **audit 增加外部锚**: 五检之上加第六检 A6: 用几何特征复核表数据 (如 δ=0 蓝基准 → CY 应 ≈0 且 β 镜像对称恢复为判据; 这是几何层推出来的外部真值, 不来自表内部)。
3. **决策落地当天做"引用面扫描"**: `grep -rn "cfd_geom_multi\b"` 类的引用面排查, 输出到复盘文档。

## 2. 项目复查 (按曼波钦点逻辑链)

**目标链**: 扫气表 (风向×舵面自由度全覆盖) → lookup_aero 查力 → MuJoCo 积分 → 下一瞬态姿态/动能。

| 环节 | 覆盖 | 状态 |
|---|---|---|
| 风维 V×α×β | 4×13×7 = 364 | ✅ 网格全覆盖 (蓝基准重跑中, qianli ~36h) |
| 舵维 δ1..δ4 | **分层协议**: 层1 δ=0 基线 / 层2 单舵 ±10/±20° / 层3 耦合校验 / RL 期按需补点 | ⚠️ **层1 重跑中, 层2/3 未跑** (全笛卡尔 23 万工况不可行, 10-23 定) |
| 查表 lookup_aero | 六维三线性插值, 热加载, 出域警告 | ✅ 代码就绪, 等蓝表回归测试 |
| 积分 MuJoCo | 6DOF, F/M_B 输入 | ✅ 已验证加载 (质量参数除外) |
| 动导数 ω 项 | 表内无 Cmq/Clp | ⚠️ 准定常近似, k=ωL/2V≪1 成立 (巡航 ~0.06); 大机动误差上升, T2 瞬态统计兜底 |
| 质量参数 | mass=160g (曼波定) / com+inertia PLACEHOLDER | 🔴 **等实机称重 (曼波)**——积分链的最大不确定性 |

**结论**: 链路无断环; "全面"二字在舵维层2/3 跑完前不能签。交付声明必须写清覆盖边界。

## 4. 下一步部署设计 (按依赖排序)

```
[P0] T0-v2 蓝表出全 (qianli CPU, ~36h, 无人值守)
  ↓ 出表当天:
[P1] 拉表回桌面 → audit A1-A5 + 新增 A6 (CY≈0 + β镜像恢复判据)
     → 通过: 与 T1-v2 合并 → lookup_aero 全域回归 → v0.95 交付
[P1'] 同日发车: 舵效层2 (单舵 ±10/±20° × 4舵 = 16 几何 × 抽样工况, qianli CPU 排 T1-v2 之后)
[P2] T2 R8b 发车 (GPU 空闲, 与 CPU 线互不抢核): 平行基准融合 STL + SUBGRID(LES) 编译
     → 瞬态统计 + 与 FVM 趋势对拍 → v1.0 拟真度背书
[P3] 层3 耦合校验点 (双舵组合抽验叠加假设) + RL 期按需补点通道 (append-only 协议已定)
```

**桌面职责清单** (打杂本位): A6 审计工具开发 / 对拍验收 / 拉表合并 / git 中心 + push / 进度条 / 文档与交付声明 / T2 数据分析。

**qianli 职责**: T0-v2 → T1-v2 → 舵效层 → T2 R8b (GPU 并行)。链式脚本已上岗, 无需人守。
