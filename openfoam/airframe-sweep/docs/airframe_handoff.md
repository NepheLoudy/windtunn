# 镖体几何 + 操纵面自由度 交接规范

> 2026-10-21 | 用途: 曼波（CAD/Fusion）→ CFD 侧（扫气 + MuJoCo 模型）
> 核心: **不需要你导出每个舵偏角度的几何**。只要给出「每片操纵面独立 STL + 铰链线」，
> CFD 侧按角度本地旋转生成任意舵偏组合，同一份定义同时喂给 MuJoCo 的 hinge joint。

## 1. 一句话需求

| 要给的东西 | 说明 |
|---|---|
| `body.stl` | 弹体/翼面本体（不含操纵面），零舵偏位形 |
| `fin_<name>.stl` ×N | **每片操纵面单独一个 STL**，零舵偏位形，弹体系绝对坐标 |
| 每片操纵面的**铰链线两端点坐标** | 弹体系两点 `[x,y,z]`，两点连线即转轴 |
| 每片的行程范围 | 如 ±20° |
| 质量/质心/惯量 | 整机一份即可（Fusion: 检查 → 物理属性） |
| 舵面布局示意 | 哪片是 δ1/δ2/δ3/δ4，或者直接说"左/右副翼 + 上下" |

坐标系: **B 系 = x 前弹轴, y 右, z 下, 右手系**；原点请注明（建议弹体几何中心或质心，
写清楚就行，CFD 侧会整体平移对齐）。

## 2. 怎么把铰链线交出来（Fusion 三种方式，从易到难）

**方式 1 — 直接量两个点（最省事）**
在 Fusion 里对着铰链位置（两片舵面之间的分缝线 / 舵轴轴线）用「检查 → 测量」，
取这条线上**两个不重合点的坐标**，填进 JSON 的 `hinge_line`。
两点取在舵根两端最直观，位置精度到 1mm 就够。

**方式 2 — 建模时留一条构造轴**
在 Fusion 里沿铰链做一条 `构造轴`（两点构造线 / 圆柱面的轴），命名成 `hinge_fin1` 之类。
导出时把名称和两端点坐标一起报给我。装配体里有 revolute joint 的话，
joint 的 origin + axis 就是铰链线，直接抄。

**方式 3 — 你已经建了运动副**
Fusion 的旋转关节（Revolute Joint）自带 origin 和旋转轴；把每个关节的名称、
origin、axis 报给我即可，无需重新量。

## 3. 导出 STL 的注意点

1. **必须拆件**：Fusion 里用「修改 → 拆分实体」，把每片操纵面从翼面/弹体上切下来，
   分组件导出。一体成型也可以——分缝处本来就是机械铰链的缝。
2. **舵根留一点嵌入量**：操纵面 STL 的根部往弹体内**多伸 2~3 mm**。否则一偏转，
   根部会和本体之间出现刀片状缝隙，CFD 里会变成漏流/奇异网格（我在生成器里默认留 3mm）。
3. **零舵偏位形**：导出时所有操纵面都摆在 0°，别带角度。
4. **单位米、坐标不动**：STL 用米制，保持 CAD 坐标（不要另建零件坐标系）。整体平移我来做。
5. **三角面片数量**：每片 ≤ 5 万三角面；超了 Fusion 导出时勾「细化/简化」降一档，
   snappyHexMesh 不在乎片数，但 STL 太大会拖慢表面相交判断。

## 4. 自由度怎么进到两个仿真里

**CFD（OpenFOAM）**：不需要动网格。CFD 侧用 `deflect_stl.py` 把 `fin_*.stl`
绕 `hinge_line` 旋转指定角度（右手定则，A→B 方向为轴），与 `body.stl` 一起拼成
`constant/triSurface/` 表面组 → 每个舵偏组合就是一个独立工况。所以：
**你给 0° 位形 + 铰链线，我这边能出任意 (de, da, dr) 组合**。

**MuJoCo**：同一条铰链线直接变成 `<joint type="hinge" axis="u v w" pos="x y z">`，
`range` 就是你的行程。舵面 STL 作为 geom。

## 5. 如果操纵面不止 4 片 / 不是十字布局

告诉我实际片数与布局（发个截图最快），并说明控制分配意图，例如：
- 三角翼两侧升降副翼（elevon）：左/右各一片，`de=(左+右)/2`、`da=(左−右)/2`
- 十字布局 4 片：`de=(上+下)/2` 同向俯仰、`da=(上−下)/2` 差动滚转、`dr=左+右` 偏航
- 若有独立方向舵/副翼，也照实说，我按你的分配写混控矩阵。

## 6. 填这个文件

模板: `airframe_assembly.example.json`（同目录）。填完和 STL 一起放进
`openfoam/airframe-sweep/cad/<版本号>/`，我跑：

```bash
python3 deflect_stl.py cad/v1/airframe_assembly.json --de 0 --da 0 --dr 0 \
  --out ~/openfoam/airframe-sweep/run_V25_a4/constant/triSurface
```

确认几何+铰链无误后，再开扫气。

## 7. 质量属性从哪来

Fusion: 选中组件 → 检查 → **物理属性**。要三样：
- 整机质量 [kg]
- 质心坐标（弹体系）[m]
- 主惯量 Ixx/Iyy/Izz [kg·m²]（绕质心）

这三个直接决定 MuJoCo 的 inertial 和气动力矩参考点（CofR）。CFD 侧只需要
**质心**用来算力矩；质量/惯量给 MuJoCo 用。
